# Nute Notes для Windows и Ubuntu

В [выпуске 0.5.0](https://github.com/mrnuked/nute-notes/releases/tag/v0.5.0) есть готовый пакет `Nute-Notes-0.5.0-Ubuntu-amd64.deb`. Windows распространяется исходниками; готовый EXE не опубликован. Собственную сборку проверяйте с тестовым профилем.

Ubuntu-пакет собран, установлен и запущен в Ubuntu 24.04 внутри WSL с Xvfb и GNOME Keyring. Проверены защищённая связка, изоляция клиента, выбранный профиль сервера и фоновая отправка после закрытия окна. Полный рабочий стол GNOME, Wayland и Ubuntu 26.04 отдельно не проверялись. Новый Windows-установщик не собирался.

## Установка готового Ubuntu-пакета

Скачайте `.deb` и контрольные суммы со страницы выпуска, проверьте скачанный файл и выполните в его каталоге:

```bash
sudo apt install ./Nute-Notes-0.5.0-Ubuntu-amd64.deb
```

Для готового пакета Node.js и npm не требуются.

## Сборка

Получите репозиторий целиком. Нужны Node.js 24, npm и интернет для зависимостей. Серверную конфигурацию и пользовательские профили в сборку добавлять нельзя.

### Ubuntu x86-64

Целевые системы — Ubuntu Desktop 24.04/26.04 на Intel/AMD x86-64. ARM не предусмотрен этой инструкцией. Из корня репозитория:

```bash
cd apps/linux
npm ci
npm run dist
sudo apt install ./release/Nute-Notes-0.5.0-Ubuntu-amd64.deb
```

Запускайте **Nute Notes** из меню ОС или командой `nute-notes` обычным пользователем, без `sudo`. Нужны защищённая связка ключей и графическое окружение. Wayland и нестандартные окружения требуют собственной проверки.

### Windows x64

В PowerShell из корня репозитория:

```powershell
Set-Location apps/windows
npm ci
npm test
npm run dist
```

Результат — `apps/windows/release/Nute-Notes-0.5.0-Windows-x64-Setup.exe`. Без вашего сертификата подписи файл может вызывать предупреждение Windows; не выдавайте его за подписанный выпуск. Проверяйте происхождение исходников и контрольную сумму результата.

## Адрес сервера

При полном запуске выберите HTTPS-домен, например `https://notes.example.org`. Принимается домен без порта, пути, параметров и учётных данных; международный — в punycode.

Разные домены имеют отдельные данные, cookie и очередь. Выбор адреса не переносит заметки, не регистрирует владельца и не подтверждает надёжность сервера: вводите пароль только на доверенной установке.

Создание владельца описано в [серверной инструкции](INSTALL.md). Доверие устройству действует 180 дней.

## Локальные секреты

Windows использует DPAPI, Linux — GNOME Keyring либо поддерживаемый защищённый KWallet. Разблокируйте связку системным паролем. Linux прекращает запуск без защищённого backend; перехода к открытому `basic_text` нет.

Не используйте `--no-sandbox` и не отключайте глобальную защиту системы. Пакет Ubuntu содержит отдельное AppArmor-правило для `/opt/Nute Notes/nute-notes`.

Профили находятся в `~/.config/Nute Notes` в стандартной Linux-конфигурации и `%APPDATA%\Nute Notes` в Windows, внутри `servers/`. Не удаляйте их при проблеме: там могут быть неотправленные правки. Копирование файлов на другой компьютер не переносит ключи DPAPI/связки.

## Фоновая работа

После первого входа и загрузки коллекции можно редактировать обычные заметки без сети. Очередь остаётся зашифрованной и отправляется при доступной синхронизации.

Крестик **скрывает окно**, но не завершает процесс. Верните окно через трей или повторный запуск. Если Ubuntu не показывает трей, повторный запуск возвращает существующее окно.

Полностью завершайте приложение через пункт выхода в меню. После этого, выхода из ОС или выключения отправки нет до следующего запуска и выбора того же сервера. Автозапуск Ubuntu не настраивается автоматически.

Перед выбором другого сервера дождитесь синхронизации или сделайте экспорт. Очередь прежнего адреса остаётся в его профиле до возвращения к нему.

## Обновление и удаление

Сначала синхронизируйте коллекцию и сохраните экспорт. Установите новый пакет, сохранив профиль и связку. Для Ubuntu: `sudo apt install ./новый-пакет.deb`.

Удаление Ubuntu-пакета: `sudo apt remove nute-notes`.

Не совмещайте удаление программы с удалением данных, пока не убедитесь, что все правки есть на сервере или в экспорте. Публичный выпуск имеет собственную идентичность приложения; не переносите профили другого клиента автоматически.
